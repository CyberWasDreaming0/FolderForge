# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-03-28

### Added

- **Template Selector** — Browse and select from pre-built folder structure templates
- **Template Builder** — Visual drag-and-drop tree editor to create custom templates
- **Variable Substitution** — Use `{project_name}`, `{date}`, `{year}`, and custom variables
- **Bulk Generation** — Create numbered sequences `{1..10}` or named sets `{Mon,Tue,Wed}`
- **Scan to Template** — Scan existing folders and convert them to reusable templates
- **File Copying** — Attach files from disk to templates; files are copied on creation
- **Optional Nodes** — Toggle individual folders on/off before creating a structure
- **Inline Rename** — Double-click any node in the tree editor to rename it
- **Undo / Redo** — Full state history stack with `Ctrl+Z` and `Ctrl+Y` shortcuts
- **Template Search** — Filter templates by name, category, or description
- **Creation History** — Track all previously created folder structures
- **Dark Theme UI** — Premium dark interface with neon green accent
- **Built-in Templates** — Premiere Pro, Downloads, Software Dev, Unity, Freelance Client
- **Windows Installer** — Packaged as a Windows desktop application via Electron
